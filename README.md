# TikTok 팔로우 매니저

틱톡 팔로잉/팔로워를 관리하고, 선택한 계정 또는 팔로잉 전체를 언팔로우하는 단일 HTML 프로그램입니다. (팔로워 삭제 기능은 없음)

- 파일: `tiktok-follow-manager.html` — 내려받아 브라우저로 열면 바로 동작합니다.

## 사용법
1. **① 계정 연동** 탭에서 "수집 스크립트 복사"
2. PC 브라우저로 tiktok.com 내 프로필 페이지를 열고 F12 → Console에 붙여넣어 실행
3. 다운로드된 JSON 파일을 프로그램에 끌어다 놓기
4. **③ 목록**에서 계정 선택 → **④ 언팔로우 작업**에서 스크립트 생성 → 틱톡 콘솔에서 실행

모든 데이터는 브라우저(localStorage)에만 저장되며 서버로 전송되지 않습니다.
