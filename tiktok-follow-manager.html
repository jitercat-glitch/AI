작동 방식 — 틱톡 공식 API는 팔로워/팔로잉 목록 조회와 언팔로우 기능을 외부에 제공하지 않습니다. 그래서 이 프로그램은 내 브라우저에 로그인된 틱톡 세션을 그대로 사용합니다. 아이디/비밀번호를 입력받지 않으며, 데이터는 이 브라우저(localStorage)에만 저장됩니다.

방법 A · 브라우저 연동 (실시간 수집, 추천)

PC 크롬/엣지에서 틱톡에 로그인한 뒤, 수집 스크립트를 한 번 실행하면 팔로잉·팔로워 목록 파일이 자동 저장됩니다.

  1. PC 브라우저로 tiktok.com에 로그인하고 내 프로필 페이지(주소가 tiktok.com/@내아이디)를 엽니다.
  2. 아래 수집 스크립트 복사 버튼을 누릅니다.
  3. 틱톡 탭에서 F12 → Console(콘솔) 탭 → 붙여넣기 Ctrl+V → Enter.
    크롬에서 처음엔 allow pasting 을 입력하라고 나오면 그대로 입력 후 다시 붙여넣기 하세요.
  4. 팝업이 자동으로 열리고 스크롤되며 수집됩니다. 끝나면 tiktok_follow_….json 파일이 다운로드되고 클립보드에도 복사됩니다.
  5. 그 파일을 아래 파일 불러오기에 넣거나, 클립보드 내용을 붙여넣기 칸에 붙여넣으세요.

도움말 · 자주 묻는 질문

왜 틱톡 로그인 버튼이 없나요?

틱톡 공식 Login Kit는 프로필·통계(팔로워 수 등)만 제공하고, 팔로워/팔로잉 목록이나 언팔로우 API는 제공하지 않습니다. 그래서 이미 로그인된 브라우저 탭에서 실행되는 스크립트 방식을 사용합니다. 비밀번호를 어디에도 입력하지 않습니다.

스크립트 실행 시 "요소를 찾을 수 없습니다" 오류

반드시 본인 프로필 페이지(URL이 /@내아이디)에서 실행해야 합니다. 틱톡이 화면 구조를 바꾼 경우에도 발생할 수 있습니다. 페이지를 새로고침한 뒤 다시 시도해 보세요.

수집된 인원이 실제보다 적어요

틱톡 웹의 팝업은 스크롤 로딩이 느릴 수 있습니다. 설정에서 스크롤 대기 시간을 늘리거나(아래), 방법 B의 공식 데이터 내보내기를 사용하면 전체 목록을 정확히 받을 수 있습니다.

언팔로우 중 아무것도 안 눌려요

틱톡 화면 언어가 한국어/영어가 아니면 버튼 문구를 위 설정에 추가하세요. 또 드라이런 옵션이 켜져 있지 않은지 확인하세요. 콘솔 로그에 어떤 버튼 문구가 발견됐는지 출력됩니다.

데이터는 어디에 저장되나요?

이 HTML 파일을 연 브라우저의 localStorage에만 저장됩니다. 서버로 전송되지 않으며 '데이터 초기화'로 지울 수 있습니다.
